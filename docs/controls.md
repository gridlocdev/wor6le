# Controls

|                     | Keyboard                    | Mouse or touch |
| ------------------- | --------------------------- | -------------- |
| Type a letter       | `A` to `Z`                  | Click or tap the letter on the on-screen keyboard |
| Delete a letter     | `Backspace` or `Delete`     | **⌫** |
| Submit the guess    | `Enter`                     | **ENTER** |
| Start a new game    |                             | **New Game** (**↻**) at the top left |
| How to play         |                             | **How to Play** (**?**) at the top right |
| Statistics          |                             | **Statistics** (a bar chart) at the top right |
| Settings            |                             | **Settings** (a gear) at the top right |

The buttons' names show as tooltips when you point at them. Letters you type past the sixth are ignored, and nothing can be typed once the game is over.
